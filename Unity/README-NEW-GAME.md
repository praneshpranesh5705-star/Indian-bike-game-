# AI Indian Bike Game — New Build

This is a new original game direction built in the existing Indian-bike-game repository. It is **not** a modification of the existing third-party APK.

## Vision
A mobile Indian-style open-world bike game with a built-in smartphone. The phone contains a real in-game **Bike AI** app.

## First playable milestone
1. Third-person bike controller
2. Small Indian city/road test map
3. Enter/exit bike
4. In-game phone UI
5. Phone > Internet > 🤖 Bike AI
6. AI chat screen
7. Secure backend connection (API key stays on server)
8. AI-generated driving challenges

## Phone apps
- 📞 Contacts
- 🌐 Internet
- 🗺️ Map
- 🎵 Music
- 📷 Camera
- 🏍️ Garage
- 🤖 Bike AI

## Bike AI capabilities
- Recommend a bike for the current mission
- Create driving challenges
- Give route suggestions
- Give riding tips
- Explain bike upgrades
- Generate short missions

## Later phases
- Traffic AI
- Police/chase system
- Weather and day/night
- Fuel and damage
- Bike customization
- NPC conversations
- Voice input/output
- Leaderboards and online features

## Important
Use original game assets, names, characters, maps, and UI. Do not copy proprietary assets from another commercial game.

The repository currently contains the integration scaffolding; the actual playable Unity project/assets still need to be created or supplied before an APK can be built.
