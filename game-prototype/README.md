# Indian Bike AI Game — Prototype

This is the first playable browser prototype for the new original game concept.

## Prototype features
- Third-person-style bike driving view
- Touch controls for mobile
- In-game phone
- Phone app grid
- **Bike AI** app inside the phone
- AI-style bike recommendations
- AI-style mission/challenge generation

## Roadmap
1. Replace prototype bike with an original 3D bike model.
2. Add a real 3D city/open-world environment.
3. Connect Bike AI to a secure server-side OpenAI integration.
4. Add actual mission state, checkpoints and rewards.
5. Package the game as Android/iOS.

The existing APK is not modified; this is a clean original prototype built in the same repository.
